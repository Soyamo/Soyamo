### 🤖 [DeepGuard — AI-Powered Deepfake Detection System](https://github.com/Soyamo/DeepGuard)

My Computer Science Honours research project, developed to identify manipulated video content using deep learning.

- Developed a hybrid deep learning approach combining **Convolutional Neural Networks (CNNs), Long Short-Term Memory (LSTM) networks, and Vision Transformers (ViTs)**.
- Achieved approximately **92% detection accuracy** in reported experiments.
- Built a **Flask-based web application** allowing users to upload and analyse videos.
- Implemented visual analytics, frame analysis, and downloadable PDF reports.
- Explored the intersection of **Artificial Intelligence, Deep Learning, and Cybersecurity**.

**Tech Stack:** Python, Flask, OpenCV, CNN, LSTM, Vision Transformers, HTML, CSS, JavaScript.

### ☁️ [Transaction Anomaly Tracker](https://gitlab.com/soyamovakala/it08x30_software_factories_221018010)

A cloud-deployed application designed to monitor financial transactions and support the identification of suspicious activities.

- Developed backend RESTful APIs using **Python and Flask**.
- Used **MySQL** for transaction data storage and management.
- Implemented automated CI/CD pipelines using **GitLab CI/CD and Docker**.
- Integrated automated build, testing, and security scanning processes.
- Deployed the application to **Google Cloud Run** using Artifact Registry.
- Reduced deployment time by approximately **65%** through CI/CD automation.

**Tech Stack:** Python, Flask, MySQL, Docker, GitLab CI/CD, Google Cloud Run, Google Artifact Registry.
